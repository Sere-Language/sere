# Sere releases

[pre-0.1.4](https://github.com/Sere-Language/sere/releases/tag/pre-0.1.4)

- Windows: `pre-0.1.4.zip`
- Linux: **`Sere-pre-0.1.4-linux-x64.tar.gz`** (prefer this). `linux.zip` is the same tree as a zip.

```bash
curl -L -O https://github.com/Sere-Language/sere/releases/download/pre-0.1.4/Sere-pre-0.1.4-linux-x64.tar.gz
tar -xzf Sere-pre-0.1.4-linux-x64.tar.gz
cd Sere-pre-0.1.4-linux-x64
chmod +x install.sh
./install.sh
```
